# SwiGLU CUDA 优化实验

## 实验假设

原始 Kernel 将两个输入暂存到 shared memory，但每个线程只读取自己的两个元素，没有线程间数据复用。因此实现了一个寄存器直算版本：直接读取两个输入，在寄存器中计算 `SiLU(x) * gate`，删除 shared-memory 往返和 block 同步。

## 正确性

寄存器版本与原始版本在 128、2048、11008、131072 个元素上对比，最大绝对误差均为 `0`。已有 CPU/CUDA SwiGLU 测试继续通过。

## CUDA Event 结果

测试条件：RTX 3050 Laptop、20 次预热、200 次重复。

| 元素数 | 原始 Kernel | 寄存器直算 | 加速比 |
|---:|---:|---:|---:|
| 128 | 0.0027 ms | 0.0029 ms | 0.94× |
| 2,048 | 0.0025 ms | 0.0028 ms | 0.87× |
| 11,008 | 0.0032 ms | 0.0040 ms | 0.81× |
| 131,072 | 0.0076 ms | 0.0079 ms | 0.96× |

## 结论

这个优化假设没有得到收益，寄存器版本在所有测试尺寸上都略慢。原因可能包括当前 Kernel 已受启动开销/特殊函数吞吐限制，以及 shared memory 的代价并未成为主要瓶颈。由于没有稳定加速，默认推理仍保留原始实现；该实验作为“基于测量否决优化”的记录保留。
