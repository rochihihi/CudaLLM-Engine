# RMSNorm CUDA 优化实验

## 实验假设

原始 RMSNorm 使用 CUB BlockReduce 完成平方和 reduction。实验版本改用 Warp Shuffle：先在每个 Warp 内归约，再由第一个 Warp 汇总 4 个 Warp 的结果，随后复用同一 scale 完成向量化归一化。

## CUDA Event 结果

测试条件：RTX 3050 Laptop、20 次预热、200 次重复。

| 元素数 | 原始 Kernel | Warp Shuffle | 加速比 |
|---:|---:|---:|---:|
| 32 | 0.0032 ms | 0.0034 ms | 0.95× |
| 768 | 0.0035 ms | 0.0036 ms | 0.96× |
| 2,048 | 0.0043 ms | 0.0086 ms | 0.50× |
| 11,008 | 0.0114 ms | 0.0112 ms | 1.01× |

所有尺寸的最大绝对误差均为 `0`。

## 结论

Warp Shuffle 版本没有表现出稳定收益，在小尺寸和 2048 维输入上反而更慢；11008 维的 1.01× 属于测量噪声范围。因此不替换默认 Kernel。该实验说明 reduction 方式本身不是当前 RMSNorm 的主要瓶颈，继续优化需要结合更低精度、融合或批量化，而不是只改归约指令。
